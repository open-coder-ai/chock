# Support

- **Questions and ideas** → [Discussions](https://github.com/open-coder-ai/chock/discussions).
  Telling us what's confusing *is* a contribution.
- **Bugs** → [open an issue](https://github.com/open-coder-ai/chock/issues/new/choose) with a
  reproduction. `chock check` output and your `chock --version` help a lot.
- **Security vulnerabilities** → [private security advisory](https://github.com/open-coder-ai/chock/security/advisories/new),
  never a public issue. Details in [SECURITY.md](SECURITY.md).
- **Docs** → start at the [documentation index](docs/README.md) and the
  [CLI reference](docs/cli-reference.md).

There is no paid support or SLA; this is an open-source project. Maintainers aim to give
first feedback on issues and PRs within a few days.
