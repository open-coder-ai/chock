- A gate's `on` accepts `prompt_submit` (`content_regex` and `script` kinds): it judges the prompt a person submits, before the model reads it. The hook is written only for agents agentseam grades able to refuse a prompt (Claude Code, Codex CLI, Cursor, Devin, Factory Droid, Gemini CLI, OpenHands, Tabnine, Windsurf); Cline, Goose and Grok can only notice one and get no entry, which `chock sync` says. The refusal carries the gate's message, never the prompt, and the decision log never stores it. Eval cases take `event: prompt_submit` with a `prompt`. Untested in a live client except Claude Code, whose refusal of a prompt was witnessed on 2026-11-26; `file_changed` stays detect-only and is not a gate event.
