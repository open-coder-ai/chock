This folder contains reference documentation for the framework tools.

## Tools

### chock check

Validate artifacts, enforcement-matrix traceability, and framework wrapper/template integrity.

Usage:

```bash
chock check
chock check --only validate --mode frontier-claude
chock check --only matrix
```

Flags:

| flag | purpose |
|---|---|
| `--repo PATH` | repo root to check (default `.`) |
| `--only <targets>` | comma-separated subset of `validate,verify,evals,matrix,index` |
| `--mode frontier-<agent>` | frontier validation profile, passed to `validate` |
| `--event <event>` | hook event context (e.g. `commit`), passed to `validate` |

Machine-readable output is not yet a stable surface; exit codes are the contract.

### chock registry

Usage:

```bash
chock registry init
chock registry scan
chock registry list
chock registry list --type skill
chock registry get chock-init
chock registry resolve chock-init
```

Registry file `.chock/registry.json` is generated by `scan` and should not be hand-edited.
